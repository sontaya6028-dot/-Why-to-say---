# "Why to say แบบนี้บูลลี่ไหม"
 เพื่อวัดระดับความคิด หรือพฤติกรรม ที่เกี่ยวกับการกลั่นแกล้งทางออนไลน์ (Cyberbullying) ้จะทำการบันทึกคะแนนในแต่ละคำตอบของบุคคลนั้น ๆ และจะ สรุปผลคะแนน พร้อมทั้งสะท้อนผลลัพธ์ของคะแนนที่ปรากฏ เพื่อให้สามารถทราบระดับความคิด หรือ พฤติกรรมแต่ละด้านของตนเอง และเว็บไซต์ที่จัดทำ จะมีการแนะนำแหล่งข้อมูล เพื่อให้คำปรึกษาแก่บุคคลที่ต้องการความช่วยเหลือ
