# "Why to say แบบนี้บูลลี่ไหม"
วัยรุ่นเป็นช่วงเวลาแห่งการเปลี่ยนแปลงทั้งในด้านร่างกาย อารมณ์ และสังคม ซึ่งมักให้ความสำคัญกับกลุ่มเพื่อนและการยอมรับจากคนรอบข้าง และบางคนอาจยังมีประสบการณ์ในการจัดการกับอารมณ์ของตนเองไม่มาก หากไม่สามารถควบคุมหรือแสดงอารมณ์ได้อย่างเหมาะสม ก็อาจนำไปสู่พฤติกรรมก้าวร้าวหรือการกลั่นแกล้งผู้อื่นได้ และในบางกรณีวัยรุ่นเองก็อาจกลายเป็นผู้ถูกกลั่นแกล้งได้เช่นกัน (Gabrielli et al., 2021)
ในปัจจุบันการเข้าถึงโซเชียลมีเดียเข้าถึงได้ง่ายและรวดเร็ว อีกทั้งผู้ใช้บางคนสามารถปกปิดตัวตนของตนเองได้ ทำให้ผู้กระทำบางคนอาจไม่คิดถึงความรับผิดชอบและผลกระทบที่เกิดขึ้นกับผู้อื่น เมื่อเทียบกับการกลั่นแกล้งที่เกิดขึ้นต่อหน้า (Gabrielli et al., 2021) นอกจากนี้ การใช้สื่อสังคมออนไลน์เป็นเวลานาน ทำให้เกิดการเปรียบเทียบตนเองกับชีวิตของผู้อื่น รวมถึงการพบเห็นเนื้อหาที่ไม่เหมาะสม อาจส่งผลต่อความรู้สึกมีคุณค่าในตนเองน้อยลง และเพิ่มโอกาสที่จะเกิดพฤติกรรมก้าวร้าวบนโลกออนไลน์ (Khalaf et al., 2023)
รวมถึงการขาดทักษะด้านสังคมและอารมณ์ เช่น การปรับตัว การควบคุมอารมณ์ การเห็นอกเห็นใจผู้อื่นและการรับมือกับความเครียด ทักษะเหล่านี้สามารถช่วยรับมือกับปัญหาหรือเหตุการณ์ที่เกิดขึ้นได้ดีขึ้น ถ้าขาดทักษะดังกล่าวอาจทำให้รับมือกับการถูกกลั่นแกล้งได้ยาก โดยเฉพาะในกรณีที่มีการเปิดเผยข้อมูลส่วนตัวบนโลกออนไลน์ตั้งแต่อายุยังน้อยและยังขาดความรู้ในการใช้สื่อดิจิทัลอย่างปลอดภัย (Gabrielli et al., 2021)
นอกจากนี้ สภาพแวดล้อมในครอบครัวก็มีส่วนเกี่ยวข้อง หากวัยรุ่นไม่ได้รับการดูแลเอาใจใส่อย่างเหมาะสม หรือโตมาในครอบครัวที่มีการใช้ความรุนแรง ก็อาจเรียนรู้และแสดงความก้าวร้าวออกมา หรือการเลี้ยงดูที่เข้มงวดเกินไปก็อาจส่งผลต่อพฤติกรรมและการแสดงออกของวัยรุ่น และอาจนำไปสู่การกลั่นแกล้งผู้อื่นได้ (Gabrielli et al., 2021)
เพื่อวัดระดับความคิด หรือพฤติกรรม ที่เกี่ยวกับการกลั่นแกล้งทางออนไลน์ (Cyberbullying) จะทำการบันทึกคะแนนในแต่ละคำตอบของบุคคลนั้น ๆ และจะ สรุปผลคะแนน พร้อมทั้งสะท้อนผลลัพธ์ของคะแนนที่ปรากฏ เพื่อให้สามารถทราบระดับความคิด หรือ พฤติกรรมแต่ละด้านของตนเอง และเว็บไซต์ที่จัดทำ จะมีการแนะนำแหล่งข้อมูล เพื่อให้คำปรึกษาแก่บุคคลที่ต้องการความช่วยเหลือ
